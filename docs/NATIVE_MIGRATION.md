# 原生迁移状态

## 范围

目标是 Android Compose / Material 3 本地阅读器。主页放继续阅读和阅读概览，本地管理书库，我的放数据管理。在线 Wenku8 发现、排行、书城、账号不进入新应用。上游历史和源码保留用于功能核对。

## 迁移方式（已调整）

不再把独立简化版作为最终实现。Android 构建入口收回原项目的 `android/`，Compose 页面位于 `app/src/compose/`，原 Flutter 页面与适配器保留，按业务边界逐项迁移。原构建配置保存于 `docs/upstream-android-build/`，可结合 Git 历史核对。

直接复用原 Kotlin 实现，整理至 `android/app/src/main/kotlin/org/mewx/wenku8_flutter/localcore/`，包名不变：

| 原项目代码 | 当前用途 |
| --- | --- |
| BookTextDecoder | TXT 编码检测、128MiB 限制、流式 UTF-8 规范化 |
| BookDocumentInput / BookDocumentZip | 原文件及描述符输入、受限 ZIP 读取 |
| LinkedTextFile / BookTextLinks | 分块读取、授权租约、关联原书、变化检测和重新关联 |
| BookOpenRequests / BookOpenTransfer | 文件管理器请求、来源能力/持久授权、无扩展名 MIME 识别、队列保存恢复；安全移动复用完整字节核对，接入原生书库确认和副本落盘 |
| BookImportQueue / BookImportWorkspace | 逐文件导入暂存、失败清理、会话隔离 |
| BookEpubWriter | TXT 内容打包成可重建 EPUB，保留原文件；内联原 512MiB 输出限制，并补齐标准 XHTML head、EPUB 元数据及未压缩 mimetype，保证 Readium 正确注入样式与脚本 |
| SpeechLocalePolicy / SystemSpeechCore | 沿用原系统朗读语言规则；从 SystemSpeechPlugin 原样提取引擎/音色/文件合成/超时与取消状态机，原 Flutter 通道改为委托该核心 |

新增 LocalTextPublication 只负责把原有解码器和打包器连接到 Readium；默认章节／卷规则和等号装饰标题处理来自 `lib/local_import_options.dart` 与 `lib/local_text_rules.dart`。现已开放 TXT 自定义章节/分卷表达式、目录预览、无标题章节命名和编码选择。规则每书保存，不回溯修改已有书的目录；旧 v2 阅读缓存沿用旧语义，新书使用带设置摘要的 v3 缓存。自定义匹配在无文档权限的独立进程内执行，只对规则计算计时，2 秒超时终止规则进程；语法错误和超时均清理暂存并保留原书。

公开源码中 BookDocuments 引用了未提供实现的 BookArchiveImport、BookMarkupImport、BookPdfImport，portable_book_prepare.dart 也未提供。现已按调用契约补齐原生适配层：复用原 libmobi C 导出器、EPUB 打包器和上游选用的 Jsoup/CommonMark/Apache POI/PDFBox 依赖；格式适配代码是迁移实现，不标为原样复用。

应用仍沿用此前迁移版的独立 applicationId；不会覆盖上游发行版。此前迁移版的数据保持可读，但上游 Flutter 数据库尚未自动迁移。旧 TXT 百分比书签按全书 positions 映射到 Readium，是近似位置；不承诺原字符级坐标精度。

## 实现约束

Readium 官方 EPUB Navigator 基于 Fragment/WebView，嵌入 Compose 的 AndroidView；应用导航、书库、设置、弹窗全部采用 Compose。Readium 的 Publication、Locator、目录和内容服务负责 EPUB 解析、位置与正文提取。

系统文档选择器仅授予用户选择的文件或目录权限，不申请全盘存储权限。默认关联原文件，复制为显式选项。备份包含原书、封面、每书设置和删除后保留的记录，不包含设备文件授权或语音模型。备份索引上限 10MiB，超限在创建输出前拒绝，避免生成无法恢复的备份。恢复前校验全部文件，元数据一次提交。当前备份恢复限制解压总大小 1GB。

ZIP 关联保留整个原包的位置与所选成员信息；HTML/Markdown 通过原包读取相对图片，不展开无关资源。显式复制 ZIP 时，同一原包仅保留一份，删除最后一本关联书后再清理。ZIP 书籍备份包含整个原包，界面明确提示；恢复后可独立离线读取。ZIP 总展开上限 1GiB、最多 12000 个成员；嵌套 ZIP 需先单独解压。HTML/Markdown、DOC、RTF 的解析上限为 64MiB；PDF 上限 2000 页，按页保持图形布局并提供提取文字用于搜索和朗读。
