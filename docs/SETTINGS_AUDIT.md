# 设置维护与验收

适用于页间阅读的 Android 预览版。使用一份本地 EPUB 和一份 TXT 测试；备份导入、词典导入和缓存清理用测试数据验证。每次改设置时同时核对菜单状态、保存后的值和使用该值的功能。

| 范围 | 可见入口 | 核对行为 |
| --- | --- | --- |
| 使用方式 | 我的 → 设置 → 使用方式 | 点书直读开关控制本地图书，覆盖书架和搜索结果两个入口。用只包含旧发现页或书架页的偏好恢复后，本地图书开关初始为关。启动页显示书架。启动续读和强制竖屏需要重启或旋转验证。 |
| 阅读与外观 | 设置 → 阅读与外观 | 外观模式菜单能选择浅色、深色和跟随系统。主题配色、字体、离线词典、阅读纪念各自打开对应页面。语音服务还需用自有测试配置单独验证。 |
| 性能与动效 | 设置 → 性能与动效 | 低性能设备模式和振动反馈可以打开。开启减少动态效果后，纸页翻动和段落接续仍能前后翻页，Readium 直接切页。关闭后重新使用所选效果。帧率上限和振动强度需真机确认。 |
| 数据与存储 | 设置 → 数据与存储 | 阅读历史、离线缓存、备份与恢复、旧版导入入口各能打开。清理插图内存只驱逐临时插图；确认与取消分别核对，用样书检查原文件和阅读位置。 |
| 阅读操作 | 阅读页 → 目录、查找、书签、外观、操作 | 目录定位和搜索跳转使用 EPUB 位置。修改字号、边距、翻页方式与页脚信息后，关闭菜单检查正文，再重进菜单或重启检查持久化。TXT 保持原阅读路径。 |
| 书架与本地管理 | 书架 → 导入书籍；书架 → 搜索书架 | 首页书架同时显示本地导入与已缓存的收藏。核对立体书架、列表、宫格、分类、来源筛选和搜索。导入菜单中的管理入口保留原本地页及其批量操作。 |
| 小组件 | 我的 → 设置 → 小组件 | 支持桌面小组件的平台显示设置入口。编辑页通过后，在系统桌面放置真实组件检查刷新。 |

## 与原项目的差异

- 书架仍能打开已缓存的旧收藏。在线发现、文库账号、出版分类和远端书架依赖独立在线组件，当前预览版没有这些入口或服务。
- EPUB 正文及选区范围由 Readium 和 Android WebView 管理。选区底色跟随阅读主题，原阅读工具条保留。首次长按遵循 WebView 的选词规则，TXT 沿用原项目按句选中的规则。
- Android 本地导入支持 EPUB、TXT 和 ZIP。HarmonyOS 尚无 Readium EPUB 导入适配。iOS 及跨设备配对需要对应设备验证。

## 模块边界

- `settings_page.dart` 负责应用设置入口和偏好表单。`pages.dart` 注入阅读历史和离线缓存的导航，设置页可独立挂载验证。通用的页面容器、入口卡片和确认菜单在 `archive_feature_ui.dart` 维护。
- `LibraryState` 拥有应用偏好、单书样式和旧备份兼容。阅读窗体行为由 `LocalPlatform` 应用，阅读菜单和正文应读取相应范围的偏好。调整已有存储键时需覆盖旧数据恢复。
- `ReaderTools` 负责阅读内菜单和表单，`ReaderPage` 负责导航和动作分派。EPUB 正文由 `ReadiumReaderBridge` 连接 Readium；翻页输入、纹理和动画由 `ReadiumPageSurface` 管理。
- 设置和平台功能有独立入口，可在各自模块扩展。阅读主页面和 `LibraryState` 仍集中跨功能协调，新增阅读选项应同时检查 Flutter 阅读路径与 Readium 路径。缩减耦合优先移动完整的职责，并用回归测试保护两种阅读路径。

## 快速检查

在与预览构建相同的 Flutter SDK 下运行：

```sh
flutter pub get
dart run tools/verify_readium.dart
dart analyze --no-fatal-warnings lib
python3 tools/check_public_source.py --revision "$(git rev-parse HEAD)"
```

预览构建还运行菜单偏好、翻页和渲染回归。Android 模拟器适合核对菜单、设置保存和阅读定位；系统小组件、振动马达、亮度与刷新率另外在真机检查。
