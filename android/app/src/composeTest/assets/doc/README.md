# Apache POI regression fixtures

The unmodified `.doc` samples come from Apache POI tag `REL_5_5_1`, directory
`test-data/document/`, under that project's Apache License 2.0. The runtime
library is the same pinned Apache POI version used by the upstream app.

Source: https://github.com/apache/poi/tree/REL_5_5_1/test-data/document
License: https://github.com/apache/poi/blob/REL_5_5_1/LICENSE

These files are packaged only in the instrumentation test APK, never in the
application APK. `fixture.pdf` in the parent directory is an original,
minimal two-page PDF generated for this project's tests.
